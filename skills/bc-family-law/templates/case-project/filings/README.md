# Filings

Court documents in this case file: everything filed by any party, plus
orders, reasons, and notices issued by the court. **Immutable** — this
folder is the court record as the parties hold it.

## Naming

Include the form/document type and date:
`form6-reply-2025-03-14.pdf`, `order-fmc-2025-06-16.pdf`,
`reasons-for-judgment-2026-05-22.pdf`.

## Maintenance

- When anything is filed or received, add it here immediately and
  record it in CASE.md's procedural history.
- Filed documents outrank everything else as sources — when a filing
  and a memory disagree, the filing wins.
- Keep served/filed versions (with stamps) rather than the last draft —
  the stamped copy is the one that counts.
