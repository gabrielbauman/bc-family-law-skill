# Rule 173 — Requirement to file additional copies if not filing electronically


Unless the party files electronic documents in accordance with Division 7 [Electronic Filing], a party who files a document under these rules must file

**(a)** one copy for the court,

**(b)** one copy for the filing party,

**(c)** one copy for each party other than the filing party, and

**(d)** if applicable, one copy for each lawyer for a child.
