# Rule 97.1 — Transition — parenting education program registries


The rules set out in this Part do not apply in respect of an application about a family law matter if

**(a)** the application was filed before January 4, 2022, and

**(b)** the registry in which the application was filed was not a parenting education program registry at the time of filing.


_Amendments: [en. B.C. Reg. 302/2021, Sch. 1, s. 7.]_
