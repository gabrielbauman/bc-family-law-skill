# Inbox

**Drop anything new here** — court documents, letters, financial
statements, message exports, photos of paper documents. Any format, any
filename. You don't need to figure out where things belong.

At the start of the next session everything in this folder gets
identified, named properly, filed into the right place, recorded in
CASE.md, and committed. You'll be told where each item went and asked
about anything unclear.

(You can also drop files anywhere else in the project — they'll be
found. This folder just saves you deciding.)

One thing not to do: edit files already in `evidence/` or `filings/`.
If something there is wrong — a bad scan, a wrong version — drop the
replacement here or just say so, and it will be swapped properly with
the history preserved.
