# Research Index

Extractions, summaries, and analysis of evidence. **Hints for
investigation, not authoritative sources** — verify against `evidence/`
and `filings/` before relying, and cite primary sources (never research
files) in case documents.

## Citation standards for research documents

Every research file records its **purpose**, **source + exact query or
command used**, and **extraction date**, then presents content cited per
the skill's `references/evidence-standards.md`. In particular, for chat
excerpts:

| ID | Timestamp | Sender | Message |
|----|-----------|--------|---------|
| 12345 | 2021-03-02T18:16:10 | [name] | exact text |

- Message IDs and full timestamps on every message
- Complete sequences — no dropped messages, no "..." elisions
- Long conversations split into labelled blocks with gaps stated
  between blocks, never elided within one

For emails, cite full filenames
(`YYYY-MM-DD_HHMM_Sender_to_Recipient_Subject.eml`); for documents,
filename + date + page.
